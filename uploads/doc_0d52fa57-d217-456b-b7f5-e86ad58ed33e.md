# Website Giả Lập Simple RFID v2

## Tài liệu mô tả website giả lập dữ liệu đầu vào cho Simple RFID

**Dựa trên:** API Integration Specs v1.1  
**Ngày tạo:** 2026-05-18  
**File gốc:** [Website_Gia_Lap_Simple_RFID_v2.docx](documents/Website_Gia_Lap_Simple_RFID_v2.docx)

---

## 1. Giới thiệu tổng quan

Website Giả Lập Dữ Liệu là công cụ nội bộ để kiểm thử và demo các tính năng của hệ thống **Simple RFID**. Website cho phép tạo và gửi dữ liệu mẫu đến các API của Simple RFID mà không cần kết nối với phần mềm nghiệp vụ thực tế (ERP, WMS).

**Giao diện:** Đơn giản, tập trung vào mô phỏng luồng dữ liệu đầu vào.

**4 Tính năng chính:**
1. Tạo Phiên In Ấn và Mã Hóa Nhãn
2. Tạo Phiên Xuất Kho
3. Tạo Phiên Nhập Kho
4. Tạo Phiên Kiểm Kê

---

## 2. Chức năng 1: Phiên In Ấn và Mã Hóa Nhãn

### Mục tiêu
Giả lập yêu cầu in và mã hóa chip RFID cho danh sách sản phẩm/tài sản.

### API Endpoint
- **Tạo phiên:** `POST /api/integration/create_print_job`
- **Kiểm tra kết quả:** `POST /api/integration/query_print_job`

### Form nhập liệu

| Trường | Tham số API | Mô tả |
|--------|-------------|-------|
| Mã phiên in | `session_print` | Mã job từ partner (vd: PE00007) |
| Tên phiên in | `session_name` | Tên ngắn gọn (vd: In 17 nhãn rfid metal) |
| Ngày tạo | `date_created` | Ngày khởi tạo (vd: 2026-01-18) |
| Chọn mẫu tem | `select_temp` | Mã mẫu in (vd: template01) |
| Bật RFID | `rfid_enable` | Checkbox true/false |
| Danh sách nhãn | `labels` | Mảng các nhãn với name, prod_code, serial, epc |

### JSON Mẫu
```json
{
  "session_print": "PE00007",
  "session_name": "In 17 nhãn rfid metal",
  "date_created": "2026-01-18",
  "select_temp": "template01",
  "rfid_enable": true,
  "labels": [
    {
      "name": "Elmich Workstation Tower",
      "prod_code": "VN-450558422995",
      "serial": "-1",
      "epc": ""
    },
    {
      "name": "Ly thủy tinh cao cấp",
      "prod_code": "LT-455058482932",
      "serial": "121",
      "epc": "E1"
    }
  ]
}
```

### Phản hồi API
```json
{
  "respcode": 0,
  "errmsg": "success",
  "result": {
    "print_job_id": 1234567
  }
}
```

## 3. Chức năng 2: Phiên Xuất Kho Tài sản

### Mục tiêu
Giả lập tạo phiếu xuất kho điện tử, ghi nhận giao tài sản từ kho cho cá nhân/phòng ban.

### API Endpoint
- **Tạo phiếu:** `POST /api/integration/stockout_note`

### Form nhập liệu

| Trường | Tham số API | Mô tả |
|--------|-------------|-------|
| Mã phiếu xuất | `stockout_code` | Mã duy nhất (vd: PXK-20260515-0001) |
| Tên phiếu xuất | `stockout_name` | Tên mô tả |
| Kho xuất | `warehouse` | Object: warehouse_cd, warehouse_name |
| Người nhận | `assigned_person` | Object: person_cd, person_name, department |
| Thời gian tạo | `created_at` | ISO-8601 (vd: 2026-05-15T21:05:00+07:00) |
| Danh sách tài sản | `items` | Mảng: asset_id, epc |

### JSON Mẫu
```json
{
  "stockout_code": "PXK-20260515-0001",
  "stockout_name": "Phiếu xuất kho tài sản tháng 05",
  "warehouse": {
    "warehouse_cd": "WH-01",
    "warehouse_name": "Kho trung tâm"
  },
  "assigned_person": {
    "person_cd": "NV-123",
    "person_name": "Nguyễn Văn A",
    "department": "Phòng CNTT"
  },
  "created_at": "2026-05-15T21:05:00+07:00",
  "items": [
    { "asset_id": "AST-0001", "epc": "" },
    { "asset_id": "AST-0002", "epc": "" }
  ]
}
```

### Phản hồi API
```json
{
  "respcode": 0,
  "errmsg": "success",
  "result": {
    "stockout_id": 123456
  }
}
```

## 4. Chức năng 3: Phiên Nhập Kho Tài sản

### Mục tiêu
Giả lập tạo phiếu nhập kho điện tử, ghi nhận hoàn trả tài sản về kho.

### API Endpoint
- **Tạo phiếu:** `POST /api/integration/stockin_note`

### Form nhập liệu

| Trường | Tham số API | Mô tả |
|--------|-------------|-------|
| Mã phiếu nhập | `stockin_code` | Mã duy nhất (vd: PNK-20260515-0001) |
| Tên phiếu nhập | `stockin_name` | Tên mô tả |
| Kho nhập | `warehouse` | Object: warehouse_cd, warehouse_name |
| Người gửi | `sender_person` | Object: person_cd, person_name, department |
| Thời gian tạo | `created_at` | ISO-8601 |
| Danh sách tài sản | `items` | Mảng: asset_id, epc (thường có EPC) |

### JSON Mẫu
```json
{
  "stockin_code": "PNK-20260515-0001",
  "stockin_name": "Phiếu nhập kho tài sản tháng 05",
  "warehouse": {
    "warehouse_cd": "WH-01",
    "warehouse_name": "Kho trung tâm"
  },
  "sender_person": {
    "person_cd": "NV-123",
    "person_name": "Nguyễn Văn A",
    "department": "Phòng CNTT"
  },
  "created_at": "2026-05-15T21:05:00+07:00",
  "items": [
    { "asset_id": "AST-0001", "epc": "EPC..1234567890" },
    { "asset_id": "AST-0002", "epc": "EPC..0987654321" }
  ]
}
```

### Phản hồi API
```json
{
  "respcode": 0,
  "errmsg": "success",
  "result": {
    "stockin_id": 123456
  }
}
```

## 5. Chức năng 4: Phiên Kiểm Kê Tài sản/Hàng hóa

### Mục tiêu
Giả lập tạo phiên kiểm kê, gửi danh sách tài sản theo sổ sách để đối chiếu thực tế.

### API Endpoint
- **Tạo phiên:** `POST /api/integration/create_audit_session`
- **Kiểm tra kết quả:** `POST /api/integration/query_audit_session`

### Form nhập liệu

| Trường | Tham số API | Mô tả |
|--------|-------------|-------|
| Mã phiên kiểm kê | `session_audit` | Mã từ partner (vd: KK-00013) |
| Tên phiên | `session_name` | Tên ngắn gọn |
| Ngày tạo | `date_created` | Ngày khởi tạo |
| Người yêu cầu | `user_request` | Mã/tên người yêu cầu |
| Phòng ban | `department_info` | Phòng ban sở hữu tài sản |
| Danh sách tài sản | `items` | Mảng: asset_id, serial, epc |

### JSON Mẫu
```json
{
  "session_audit": "KK-00013",
  "session_name": "Tên phiên tại kho kk02",
  "method": 0,
  "date_created": "2026-05-10",
  "user_request": "user_id123",
  "department_info": "bp kế toán",
  "store_info": "store-0001",
  "items": [
    {"asset_id": "THIAVANG-001", "serial": "123", "epc": null},
    {"asset_id": "LT-455058482932", "serial": "345", "epc": null},
    {"asset_id": "VN-45503447218", "serial": null, "epc": null}
  ]
}
```

### Phản hồi API
```json
{
  "respcode": 0,
  "errmsg": "success",
  "result": {
    "audit_id": 123456
  }
}
```

## 6. Tính năng chung của Website

### 6.1. Lưu lịch sử
- Mỗi phiên tạo thành công được lưu vào bảng "Lịch sử" trên website
- Hiển thị: mã phiên, thời gian tạo, trạng thái, kết quả

### 6.2. Tạo dữ liệu mẫu
- Có thể tùy chỉnh giá trị hoặc dùng giá trị mặc định
- Nút "Tạo nhanh" để sinh dữ liệu mẫu ngẫu nhiên

### 6.3. Hiển thị phản hồi
- Hiển thị JSON response từ Simple RFID
- Thông báo thành công/lỗi rõ ràng

## 7. Cấu trúc Database (Tham khảo)

### Bảng `asset_note_mgmt` (Phiếu xuất/nhập)

| Cột | Kiểu | Mô tả |
|-----|------|-------|
| `id` | bigint | Khóa chính |
| `stockio_cd` | varchar(50) | Mã phiếu (PXK.../PNK...) |
| `stockio_name` | varchar(255) | Tên phiếu |
| `type_inout` | smallint | 0=xuất, 1=nhập |
| `warehouse_cd` | varchar(50) | Mã kho |
| `warehouse_name` | varchar(255) | Tên kho |
| `person_cd` | varchar(50) | Mã cá nhân |
| `person_name` | varchar(255) | Tên cá nhân |
| `department` | varchar(255) | Phòng ban |
| `date_created` | timestamp | Thời gian tạo |
| `items_data` | varchar(2048) | JSON danh sách tài sản |
| `status` | integer | 0=mới, 1=đã xử lý |
